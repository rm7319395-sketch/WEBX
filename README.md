## 💻 Running Locally

### Option A: Using the Built-in Node Server (Zero dependencies)
```bash
npm start
# or: node server.js
```
Then open: **`http://localhost:3000`** in your browser.

### Option B: Using any Static Server (e.g., Live Server or npx serve)
```bash
npx serve .
```

## 🚢 Deployment Instructions

### Deploy to Netlify
1. Drag and drop the `webx` folder into [Netlify Drop](https://app.netlify.com/drop).
2. Or link your Git repository to Netlify:
   - **Build command:** *(leave empty or `node generate-assets.js`)*
   - **Publish directory:** `.`

### Deploy to Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in the project directory, or import the GitHub repository in the Vercel Dashboard.
3. Framework Preset: **Other / Static HTML**.
